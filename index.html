PYTHON PROJECT

Area Calculator

A calculator project that uses programming logic and mathematical formulas to calculate the area of different shapes.

AREA CALCULATOR

Enter your values and calculate the area.
area_calculator.py 
print("WELCOME TO AREA CALCULATOR MANNY VERSION")

shape = input("Enter the Shape:   ")

if shape == "square":
    side = float(input("Enter the side lenght:  "))
    area = side ** 2
    print(area)

elif shape == "rectangle":
    length = float(input("Input Length:  "))
    width = float(input("Input Width:  "))
    area = length * width
    print(area)

elif shape == "triangle":
    height = float(input("Input Height:  "))
    base = float(input("Input Base:  "))
    area = (height * base) / 2
    print(area)

elif shape == "circle":
    print("NOTE pi is 3.14159")
    pi = float(input("Input pi value:  "))
    radius = float(input("Input Radius:  "))
    area = pi * (radius ** 2)
    print(area)

else:
    print("Invalid shape")
